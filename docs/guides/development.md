# Работа с репозиторием

Руководство для текущего подготовительного этапа. Android-проект пока не создан; инструкции сборки будут добавлены вместе с рабочим каркасом.

## Инструменты

Для текущего этапа нужны Git и CLI Backlog.md. При подготовке проверена работа Backlog.md `1.53.0` на Windows в PowerShell. Это версия проверки, а не выбранная зависимость Android-приложения.

Версии JDK, Android SDK, Gradle, языка и UI-инструментария пока не определены. Их установка и настройка в этот этап не входят.

## Навигация и очередь

Начни с [карты документации](../README.md) и [инструкций агента](../../AGENTS.md). Из корня репозитория:

```powershell
git status --short --branch
git remote -v
backlog task list --plain
```

Карточки и статусы описаны в [руководстве доски](../../backlog/README.md). Для запуска локальной доски:

```powershell
backlog browser
```

Браузер автоматически не открывается; используй адрес из вывода CLI. Порт настраивается в конфигурации доски.

## Проверки

При изменениях документации проверяй содержание, относительные ссылки и пробельные ошибки:

```powershell
git diff --check
git diff --cached --check
```

Эти команды проверяют только изменения, доступные Git diff; новые неотслеживаемые файлы требуют отдельной проверки. Проверь, что карта содержит все документы и что статус реализации описан честно. Изменения карточек проверяй через `backlog task view <ID> --plain`.

Тесты, линтер и сборка приложения сейчас отсутствуют. При создании Android-каркаса сюда добавляются точные версии, команды и сценарии приёмки. Не используй команды из веб-проекта-образца.

## Git

Основная ветка — `main`, remote — `origin`. Адрес репозитория указан в [корневом README](../../README.md). Порядок коммита и отправки — в [AGENTS.md](../../AGENTS.md#git).

Первичная обвязка включает конфигурацию и предъявляется до коммита. Отсутствие коммита означает, что подготовленные файлы пока существуют только локально; настройка remote сама по себе не публикует их.
