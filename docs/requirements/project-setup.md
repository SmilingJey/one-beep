# Требования к обвязке проекта

Границы подготовительного этапа по запросу пользователя. За образец принят `D:\projects\agents-chat`; переносится организация работы, а не код или стек того приложения.

## FR-SETUP-1 — Инструкции агента

В корне находятся `AGENTS.md`, `CLAUDE.md` и `TOOLS.md`. Общие правила включают SDD, ответственность агента за код, совместные значимые решения, документирование, проверки, приёмку и Git. `CLAUDE.md` импортирует `AGENTS.md`, не дублируя правила.

## FR-SETUP-2 — Документация

Есть обзор проекта, карта документации, подтверждённые требования к приложению, открытые вопросы, руководство разработчика и порядок ведения ADR с шаблоном. Будущие решения и отсутствующие команды не выдаются за принятые или работающие.

## FR-SETUP-3 — Очередь работ

Backlog.md настроен для One Beep по образцу: русские статусы, карточки с критериями, планом и итогом, отдельное хранение завершённых и отменённых задач. Автокоммиты, автоматическое открытие браузера и операции с удалёнными ветками отключены. Карточки создаются и меняются через CLI.

## FR-SETUP-4 — Репозиторий

Локальный Git использует ветку `main` и `origin`, указывающий на репозиторий из [README](../../README.md). Есть исключения локальных файлов Android, секретов, сборок и временного состояния инструментов, а также правила окончаний строк.

## FR-SETUP-5 — Границы этапа

В этот этап не входят Android-модуль, исходный код приложения, зависимости и сборочная конфигурация, выбор стека и реализация таймера. Исходный проект-образец не изменяется. Его задачи, ADR, данные и частные проблемы инструментов не копируются.

## Критерии проверки

- Все перечисленные файлы существуют, внутренние ссылки разрешаются, документация согласована с фактическим состоянием.
- CLI читает конфигурацию и карточки One Beep; очередь не содержит задач проекта-образца.
- Git показывает правильные ветку и remote; правила исключений работают для типичных локальных файлов и ключей подписи.
- Код приложения отсутствует. Тесты и сборка приложения не запускаются.
- Коммит и отправка проходят по [правилам Git](../../AGENTS.md#git); локальная подготовка не выдаётся за публикацию.
