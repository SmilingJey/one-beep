# One Beep

Простое Android-приложение: пользователь задаёт время ожидания, а по его истечении приложение издаёт звуковой сигнал, который заканчивается сам. Выключать сигнал вручную не требуется.

Репозиторий: [SmilingJey/one-beep](https://github.com/SmilingJey/one-beep).

## Статус

Подготовлена организационная обвязка: инструкции агента, документация, шаблоны архитектурных решений и доска задач. Android-проект и код приложения ещё не созданы. Сборки APK и команды запуска пока нет.

Подтверждённая идея и вопросы до реализации — в [требованиях к приложению](docs/requirements/application.md). Границы текущего этапа — в [требованиях к обвязке](docs/requirements/project-setup.md).

## Технологический стек

Целевая платформа — Android. Язык, UI-инструментарий, минимальная версия Android, версии инструментов сборки и механизм выполнения таймера пока не выбраны. Значимые решения будут оформляться в [ADR](docs/architecture/decisions/README.md) после обсуждения требований.
