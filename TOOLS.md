# Грабли инструментов

Память агента о проверенных особенностях инструментов и окружения. Правила ведения — в [AGENTS.md](AGENTS.md#грабли-инструментов).

Проверенных особенностей для One Beep пока нет. Записи из проекта-образца не перенесены: их применимость здесь не проверялась.

Формат записи: симптом заголовком, затем одна-три строки «что происходит → как правильно», версия и условия проверки при необходимости.
