# Грабли инструментов

Память агента о проверенных особенностях инструментов и окружения. Правила ведения — в [AGENTS.md](AGENTS.md#грабли-инструментов).

## Системная команда java запускает Java 8

Проверено 2026-11-23 в PowerShell: `java -version` из исходного PATH показывает Java 8, хотя отдельно установлен JDK 21. Перед Wrapper запускай `scripts/android-env.ps1` с путём JDK 21 из [руководства](docs/guides/development.md#настройка-в-windows). Скрипт меняет окружение только текущего процесса.

## Android Lint учитывает пустые каталоги ресурсов

На AGP 8.13.2 после переноса значка из `mipmap-anydpi-v26` в `mipmap-anydpi` пустая старая папка продолжала вызывать `ObsoleteSdkInt`. Удали оставшийся пустой каталог: отсутствие файлов само по себе не убирает предупреждение.
